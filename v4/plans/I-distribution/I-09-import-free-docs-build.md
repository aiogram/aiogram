## Motivation

3.x docs (`docs/conf.py`, Sphinx + furo) have 672 API pages generated by legacy butcher templates that use `automodule`
on pydantic models. Standard autodoc imports modules. On 4.x, importing anything under `aiogram/` runs
`aiogram/__init__`, which imports `_core` (D16), so the docs build would need the compiled extension and a Rust
toolchain.

D79 / R29 require:
- sphinx-autoapi for everything, with `autoapi_file_patterns = ['*.pyi', '*.py']` so stubs win over the thin
  `.py` re-exports;
- a build from the `docs` group with `--no-install-project`.

R29's acceptance asks for a proven clean build with no compiled extension, using representative cases.

## Scope

**In:**
- `docs/conf.py`: drop the `automodule` usage and the import of `aiogram`. Read the version from the I-01 version
  source by path (`tomllib` / regex), not via import.
- `autoapi_dirs = ['../aiogram']`, `autoapi_file_patterns = ['*.pyi', '*.py']`, `autoapi_type = 'python'`, options for
  inherited members, and `autoapi_ignore` for `_core` internals where needed.
- Integrate the butcher-emitted per-entity index pages (C-22): titles, grouping, cross-links.
- A CI job `docs-import-free`:
  - a fresh runner **without** a Rust toolchain;
  - `uv sync --group docs --no-install-project`;
  - `sphinx-build -W`;
  - a check that no `aiogram/_core*.so` exists and that `python -c "import aiogram"` **fails** in that env, which
    proves the build didn't import it.
- R29 representative cases checked in the built HTML: a recursive type (`Message.reply_to_message`), a helper-fragment
  member (`User.mention_html` from `_ext.pyi`), an alias (`from_user` ↔ `from`), a generated `Default(...)` default, an
  inherited member, a framework module (`aiogram.dispatcher.router.Router`).
- RTD config: a `dev-4.x` version building with the docs group, `--no-install-project`, `-W`.
- A fallback: a wheel-backed build job (installs the I-02 wheel), documented and off by default.

**Out:**
- Section restructure (I-10).
- Deprecations page generator (I-12, which plugs a Sphinx extension into this build).
- Stub content quality: docstrings, "added in Bot API x.y" and deprecation notes are C-14's.

## Checklist

- [ ] Add `sphinx-autoapi` to the docs group (lower bound only, D70).
- [ ] Rewrite `docs/conf.py`. Remove any `import aiogram`. Pick up the version by path.
- [ ] Delete the legacy automodule API page tree on `dev-4.x` (`docs/api/**` generated by legacy butcher) in favour of
      autoapi plus the C-22 index pages.
- [ ] `tests/docs/test_import_free.py` (runs in the docs job): parse `docs/_build/html` for the six R29 cases above and
      assert their anchors and signatures exist.
- [ ] **CLI reference without import:** 18 §1 asks for a CLI (17) reference. Generate it from a static spec, not by
      importing `aiogram.cli`. G-15 keeps the argparse definitions in a module that imports nothing from `aiogram`
      (agreed in G-15's scope); a small Sphinx extension here loads that file by path and renders it.
- [ ] `.readthedocs.yml` on `dev-4.x`: `uv sync --group docs --no-install-project`, `-W`.
- [ ] Wheel-backed fallback job (`workflow_dispatch`).
- [ ] Changelog fragment `CHANGES/<id>.doc.rst` (API reference generated from stubs). No registry entry.

## Acceptance criteria

- `docs-import-free` is green on a runner where `rustc` is absent (`command -v rustc` fails, asserted in the job).
- The six R29 cases are present in the HTML (test passes). Removing `*.pyi` from `autoapi_file_patterns` makes the test
  fail (stubs must win).
- `sphinx-build -W` reports zero warnings.
- An RTD preview build on `dev-4.x` succeeds.

## Rejected alternatives

| Alternative | Why rejected | Decision |
|---|---|---|
| Standard autodoc | Imports modules, so it needs `_core` | R29 |
| Mocking `_core` with `autodoc_mock_imports` | Loses the stub content; R29 prefers a fully static path | R29, D79 |
| Translating the generated reference | Narrative-only translation | D81 |
| Registry imported as a Python module for the Deprecations page | The registry is a data file read by path | PD-13 |
