The :code:`answer_*` and :code:`reply_*` shortcuts of :class:`aiogram.types.message.Message` now fill :code:`direct_messages_topic_id` from :code:`Message.direct_messages_topic`, so answers to a message in a channel direct messages chat go to the same topic (except :code:`answer_game`, :code:`reply_game`, :code:`answer_poll` and :code:`reply_poll`, whose methods have no such parameter). Since the value is filled automatically, passing :code:`direct_messages_topic_id` to these shortcuts now raises :code:`TypeError`; call the :class:`aiogram.client.bot.Bot` method directly to send to another topic.
