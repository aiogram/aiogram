Sped up :code:`import aiogram` roughly 4x (1.9s -> 0.45s on CPython 3.13) and cut the memory a process
needs for the framework from about 175 MB to about 64 MB, by building model schemas lazily instead of
on import.
Every Telegram object and method model was rebuilt eagerly at import time, which discarded the
:code:`defer_build` setting they are declared with. Forward references are now exposed through the
globals of the type modules, so pydantic resolves them when a model is first used and a process only
pays for the models it actually touches.
